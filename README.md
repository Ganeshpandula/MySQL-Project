# Employee Management System Using MySQL

## 📌 Project Overview
The Employee Management System is a database management project developed using MySQL to efficiently store, manage, and analyze employee-related information. It manages employee details, job roles, departments, qualifications, leaves, salaries, bonuses, and payroll records. The project uses SQL queries to retrieve meaningful insights and support better HR management decisions.

## 🎯 Objectives
- Store and manage employee information in a structured database.
- Maintain relationships between tables using primary keys and foreign keys.
- Retrieve employee and department details using SQL queries and joins.
- Analyze salary distribution, bonuses, job roles, and leave records.
- Generate reports to support data-driven decision-making.

## 🛠️ Technologies Used
- **Database:** MySQL
- **Language:** SQL
- **Concepts:** DDL, DML, Joins, Aggregate Functions, Subqueries, Constraints, and Group By

## 🗂️ Database Tables
- **Job Department:** Stores job roles, departments, and salary ranges.
- **Employee:** Stores employee personal, contact, and login details.
- **Salary Bonus:** Maintains salary and bonus information.
- **Qualification:** Stores employee qualification details.
- **Leaves:** Tracks employee leave records and dates.
- **Payroll:** Supports salary and payroll analysis.

## 📊 Key Analysis
- Identify departments with the highest number of employees.
- Find the top five highest-paid employees.
- Analyze job roles available in each department.
- Calculate average salary by department.
- Identify the highest-paying job roles.
- Compare total salary allocation across departments.
- Analyze employee qualifications and leave deductions.

## 💡 Key Features
- Structured employee data management.
- Relational database design with primary and foreign keys.
- Data integrity using constraints.
- SQL-based employee and salary analysis.
- Report generation using queries and aggregate functions.

## 📈 Project Outcome
This project demonstrates practical knowledge of MySQL, relational database design, SQL query writing, and data analysis. It helps organize employee information, retrieve useful insights, and support efficient workforce and payroll management.
